# Transportes Amsterdam

Sitio web de Transportes Amsterdam, empresa de transporte de carga y comercio internacional.

## Ver el sitio

Abre `index.html` en un navegador. La página funciona como sitio estático y no requiere instalar programas.

## Carpetas y archivos

```text
.
├── index.html          # Página principal: contenido, estilos y comportamiento
└── assets/
    ├── images/          # Logos, fotografías, iconos y mapa de Chile
    └── js/
        └── lucide.min.js # Iconos locales usados por la página
```

Las imágenes se cargan desde `assets/images/` y la librería de iconos desde `assets/js/`, por lo que esas carpetas deben permanecer junto a `index.html`.

## Publicación

El proyecto puede guardarse en GitHub como repositorio y publicarse con GitHub Pages. Para publicar, configura GitHub Pages para usar la rama principal y la carpeta raíz, donde está `index.html`.
